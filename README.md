## File Descriptions

| File | Description |
|------|-------------|
| `task2_syntax_pep8.py` | Demonstrates the Zen of Python, PEP 8 style conventions, snake_case variables and docstrings. |
| `task3_data_types.py` | Covers all core Python data types: int, float, bool, str, list, tuple, set, dict and type casting. |
| `task4_control_structures.py` | Shows if-elif-else grade classification, for/while loops, break/continue and a 3×3 multiplication table. |
| `task5_functions.py` | Demonstrates built-in functions, user-defined functions, default parameters, *args, lambda with map() and variable scope. |
| `task6_oop.py` | Object-Oriented Programming: Animal class with inheritance (Dog subclass), class variables, instance counter and encapsulation via a private attribute. |
| `task7_numpy_pandas_matplotlib.py` | Scientific computing with NumPy arrays, Pandas DataFrames (create + filter) and Matplotlib bar and line charts. |

| `task9_disease_diagnosis.py` | Jeshi Hospital diagnostic tool that maps symptom pairs to Typhoid, Malaria, Pneumonia or Diabetes. |
